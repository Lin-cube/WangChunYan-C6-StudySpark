## 二、C6 的具体要求

### 2.1 硬性要求（缺一不可）

| 要求 | 说明 | 本提交的对应产物 |
|------|------|------------------|
| **必须部署上线** | 有任何人可访问的公网 URL，不是 localhost | `WangChunYan_C6_app链接.md` |
| **必须集成 AI 能力** | AI 是产品功能的核心部分，不是装饰 | 产品核心功能即 AI 生成，见 AI 日志 |
| **前端必须** | 用户能看到、能交互的界面 | `app/` 目录完整前端源码 |
| **必须可用** | 打开就能用：输入 → 处理 → 输出，走通不报错 | 产品支持「演示模式」，无 Key 也能体验 |

### 2.2 「可用」的五条定义（产品必须全部通过）

1. 没见过这个 App 的人，打开链接 **30 秒内**知道它是干什么的
2. **不需要注册/登录**就能体验核心功能（或有 demo 模式）
3. 核心流程能走通：**输入 → 处理 → 输出**，没有中途报错
4. 在**手机浏览器**上也能基本使用（响应式布局）
5. **加载时间 < 5 秒**

### 2.3 AI 集成的三个层次（评分梯度）

| 层次 | 描述 | 评分 |
|------|------|------|
| 🟢 基础 | AI 做单一任务，用户触发（如文本翻译） | 及格 |
| 🔵 进阶 | AI 嵌入多步骤 workflow（如：文本→提取→生成→导出） | 艉好 |
| 🟣 深度 | AI 是持续交互的核心（如对话式助手、自适应学习） | 优秀 |

> 本产品定位：**🔵 进阶层**——「粘贴文本 → AI 结构化生成闪卡 + 自测题 → 交互式复习 → 导出 Markdown」的多步骤 workflow。
